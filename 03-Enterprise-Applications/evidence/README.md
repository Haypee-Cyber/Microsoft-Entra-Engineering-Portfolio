## Security and Validation

The implementation demonstrates group-based application access, inherited user access, SAML-based authentication and validation through Microsoft Entra sign-in and audit logging.

Screenshots published in this portfolio are reviewed before upload to ensure that credentials, secrets, tokens and unnecessary personally identifiable information are not exposed.
