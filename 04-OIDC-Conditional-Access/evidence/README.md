# Module 04 - Implementation Evidence

This folder contains practical evidence from the OIDC and Conditional Access implementation lab.

## Evidence Collected

Evidence will include:

- OIDC application configuration
- Application role configuration
- User-to-role assignments
- Decoded OIDC token and claims
- Conditional Access policy configuration
- Successful and blocked authentication tests
- Microsoft Entra sign-in logs
- Troubleshooting and validation evidence
