# Module 04 - OIDC and Conditional Access

This module demonstrates the implementation and security of OpenID Connect (OIDC) authentication in Microsoft Entra ID, including application roles, token validation, user assignments, and Conditional Access controls.

## Objectives

- Validate OIDC authentication and token claims
- Configure and test application roles
- Assign users to application roles
- Implement Conditional Access controls
- Test access behaviour
- Review Microsoft Entra sign-in logs
- Collect implementation and troubleshooting evidence
